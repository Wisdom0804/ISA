# 任务文档

每项实际开发任务在此保存一份 Markdown 记录，章节使用[项目讨论与开发决策](../project-discussion.md)第 5 节的统一模板：

1. 应用需求
2. 用户场景与输入输出
3. 相关技术
4. 方案与架构
5. 数据模型与接口
6. 实现步骤
7. 验收标准
8. 实验记录与结果
9. 设计决策与取舍
10. 未解决问题与后续决策

文档描述当前设计、实现与验收结果，不记录修改历史，不把未验证的结论写成已达成事实。
